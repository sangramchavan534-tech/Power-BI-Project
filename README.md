# Customer Churn Analysis Dashboard

## Project Overview
This project analyzes customer churn data using **Power BI** to identify customer exit patterns, retention trends, and key business insights.

## Dashboard Highlights
- Total Customers, Exited Customers, and Active Customers.
- Customer Churn Rate and Total Balance.
- Churn analysis by Year, Month, Gender, and Geography.
- Customer exit analysis by Credit Score and Age.
- Retained vs Exited Customer comparison.
- Interactive filters for better analysis.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Pages
1. **Customer Churn Overview** – KPIs and customer exit analysis.
2. **Customer Retention Analysis** – Monthly churn trends, geography, age, and retention analysis.

## Objective
To understand customer churn behavior, identify important churn factors, and support data-driven business decisions.
